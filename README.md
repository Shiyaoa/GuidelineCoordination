# GuidelineCoordination

临床指南协调系统的核心代码库。

## 项目结构

- `pipeline/` - 核心处理管道代码
  - `analyzer.py` - 分析器
  - `config.py` - 配置管理
  - `graph_api.py` - 图形API接口
  - `graph.py` - 图形处理
  - `io_utils.py` - 输入输出工具
  - `lsh_cluster.py` - LSH聚类
  - `models.py` - 数据模型
  - `processors.py` - 处理器
  - `rate_limiter.py` - 速率限制器
  - `standard_library.py` - 标准库
  - `z3env.py` - Z3环境配置
